[ How it works ]

Teams register in minutes.

01

Create your account

Name, class, school, one field of entry. About forty seconds, and you can edit all of it later.

02

Start or join a team

Leaders create a team, set its size and share the passcode. Everyone else joins with that code — same school, same field.

03

Build, then present

Prepare the object and a two-minute explanation. Judges visit every booth and leave written feedback.
